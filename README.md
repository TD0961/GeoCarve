# GeoCarve (ጂዮካርቭ)
## Heavy Machinery Import & Sales — Ethiopia

> **"Let's carve our future together."**

GeoCarve is a premier Ethiopian heavy machinery import and sales company committed to connecting the country's growing industries with equipment from leading international manufacturers (Caterpillar, Komatsu, Volvo CE, SANY, XCMG, Shantui, SDLG, Sinotruk, Zoomlion).

---

### Key Capabilities & Features

1. **Brand Identity & Humanized Visuals**
   - High-resolution, authentic photography featuring Ethiopian civil engineers, technicians, contractors, and heavy machinery operating across realistic Ethiopian terrains and cityscapes.
   - Clean dark-luxury industrial aesthetic with obsidian slate, golden amber accents, and crisp typography.

2. **Interactive Machinery Catalog & Fleet Explorer**
   - Filter by Category: Excavators & Earthmoving, Wheel Loaders, Mobile Cranes, Dump Trucks, Road Construction & Rollers.
   - Live search bar and detailed specifications modal (operating weight, engine horsepower, bucket/lifting capacity, and recommended applications).

3. **Interactive Sourcing & Quotation Builder**
   - Step-by-step modal allowing Ethiopian contractors and institutions to select machinery specs, preferred global brands, project destination in Ethiopia (Addis Ababa, Modjo, Hawassa, Mekelle, Dire Dawa, Bahir Dar, etc.), and procurement timeline.
   - Direct WhatsApp connect and Ethiopian telephone desk hotline integration.

4. **The 5-Stage Transparent Import Journey**
   - Complete visualization of the import workflow: Specification Analysis ➔ Global Factory Audit ➔ Bank LC Documentation ➔ Djibouti Port Maritime Transit ➔ Modjo Dry Port Customs Clearance & Direct On-Site Delivery.

5. **Target Industry Solutions**
   - Construction & Civil Engineering, Road & Infrastructure, Mining & Quarrying, Industrial Parks, Real Estate Development, and Government Public Works.

6. **Developing After-Sales & Genuine Spare Parts Support**
   - Dedicated service roadmap: OEM spare parts supply chains, advanced electronic/hydraulic diagnostics, preventive maintenance schedules, and operator onboarding.

---

### Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack, React 19)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Geist Sans & Geist Mono

### Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
